# LUCIANE English War Arena — Vocabulary Library

## Target size
- Adjectives: 500 entries
- Nouns: 500 entries
- Pronouns: 500 entries
- Verbs (regular and irregular): 500 entries
- Prepositions: 500 entries
- The Mixture: separate activity bank; not counted as a vocabulary category

## Required fields for every vocabulary entry
1. Headword and word class/subclass
2. IPA pronunciation, with British and American audio playback where available
3. Portuguese meaning and usage notes
4. Four natural English example sentences, each with Portuguese translation
5. Relevant inflections/forms (especially irregular verbs and countable/uncountable nouns)
6. Common errors, collocations, synonyms/antonyms where useful
7. Practice prompts for meaning, listening, spelling, sentence use and gap-fill

## Release batches
The current in-app seed contains 10 entries in each of the five vocabulary categories (50 total). These are the first verified teaching records, not the completed 500-entry libraries. The next content releases should add 50 entries per category per batch until each reaches 500. Do not pad the library with duplicate headwords, invented IPA, literal/unnatural translations or repeated example templates.

## The Mixture activity bank
Keep this bank independent from the five word lists. It should include reading comprehension, word hunts, sentence correction, translation, grammar choices, ordering, contextual cloze, short writing and timed mixed-skill rounds.
